# Bandit Level 0 — Connecting over SSH

## Goal
Connect to the Bandit game server using the starter credentials shown on the official Level 0 page.

## Commands
```bash
ssh bandit0@bandit.labs.overthewire.org -p 2220
```

When prompted, use the starter password provided by the official challenge page.

## What I learned
- `ssh` opens a secure remote shell.
- `-p 2220` specifies the non-default SSH port used by Bandit.
