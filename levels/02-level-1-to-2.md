# Level 1 -> Level 2

## Goal
The password is in a file whose name is a single hyphen (`-`).

## Commands / approach

```bash
ls -la
cat ./-
```

## What I learned
A file named - can be mistaken for an option, so I used ./- to point at the file in the current directory.
