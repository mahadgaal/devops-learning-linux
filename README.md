# DevOps Learning: Linux & OverTheWire Bandit

My notes and learning outcomes while working through the [OverTheWire Bandit wargame](https://overthewire.org/wargames/bandit/) as part of my Linux and DevOps learning.

## Goals
- Practise Linux command-line navigation and file inspection.
- Build familiarity with SSH, permissions, text processing, encoding, compression, networking and basic privilege concepts.
- Record the commands I ran and explain why they work.

## Repository structure

- `levels/00-level-0.md` — connecting to Bandit
- `levels/01-level-0-to-1.md` through `levels/20-level-19-to-20.md` — level notes

## How I document each level
1. Read the official level goal.
2. Try the challenge myself on the Bandit server.
3. Record the command(s) I used and explain the relevant Linux concept.
4. Verify the result before marking the level complete.

> **Credential note:** I intentionally do not commit Bandit passwords, private keys, or other credentials. Run the commands yourself and keep any passwords needed to continue in a private local note. Bandit passwords can change.
